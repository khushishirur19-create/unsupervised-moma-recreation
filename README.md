# Unsupervised — A Generative Study

A locally running, browser-based procedural animation inspired by Refik Anadol's *Unsupervised — Machine Hallucinations — MoMA*.

## Important scope note
This is an original procedural interpretation, not an exact reproduction of the original AI artwork. The original uses a trained machine-learning model and specialized rendering software. This project does not use the artist's source code, trained model, or MoMA artwork images.

## Interactions
- Flow intensity slider
- Particle density slider
- Four color palettes
- Playback speed slider
- Pause/resume
- Generate a new composition

## Run locally
Open `index.html` in a modern browser. No dependencies, API keys, or internet connection are required.
